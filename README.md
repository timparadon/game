# หนึ่งชีวิตในยุทธภพ

เกมภาษาไทยแบบภาพนิ่งและตัวเลือก เล่นได้โดยเปิด `index.html` หรือเริ่มเว็บเซิร์ฟเวอร์:

```sh
cd /workspace/game
python3 -m http.server 8000 --bind 0.0.0.0
```

ไม่ต้องติดตั้งแพ็กเกจหรือใช้ API key เกมใช้ HTML, CSS และ JavaScript โดยตรง มีแผนที่สี่ทิศ การกระทำรายปี การทะลวงขั้นพลัง และบันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์ ชีวิตสิ้นสุดเมื่ออายุ 80 ปีหรือพลังชีวิตหมด ฟอนต์ออนไลน์เป็นตัวเลือก มีฟอนต์สำรองเมื่อออฟไลน์

ตรวจไวยากรณ์: `node --check game.js`
