# หนึ่งชีวิตในยุทธภพ

เกมภาษาไทยแบบภาพนิ่งและตัวเลือก เล่นได้โดยเปิด `index.html` หรือเริ่มเว็บเซิร์ฟเวอร์:

```sh
cd /workspace/game
python3 -m http.server 8000 --bind 0.0.0.0
```

ไม่ต้องติดตั้งแพ็กเกจหรือใช้ API key เกมใช้ HTML, CSS และ JavaScript โดยตรง มีแผนที่สี่ทิศ การกระทำรายปี การทะลวงขั้นพลัง และบันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์ ชีวิตสิ้นสุดเมื่ออายุ 80 ปีหรือพลังชีวิตหมด ฟอนต์ออนไลน์เป็นตัวเลือก มีฟอนต์สำรองเมื่อออฟไลน์

ตรวจไวยากรณ์: `node --check game.js`

## สำนักและสายสัมพันธ์

แต่ละทิศมีสำนักและสหายประจำพื้นที่ รวม 4 สำนัก 4 ตัวละคร ฝากตัวเป็นศิษย์ได้เมื่อพลังยุทธ์ถึง 10 และมีเงิน 15 เหรียญ เข้าร่วมได้ครั้งละหนึ่งสำนัก ทำภารกิจเพื่อสะสมผลงาน เลื่อนยศทุก 30 ผลงาน และรับโบนัสการฝึกตามวิถีสำนัก การออกจากสำนักจะล้างผลงานแต่คงความสัมพันธ์ไว้

พูดคุย มอบของขวัญ และประลองฉันมิตรเพื่อพัฒนาความสนิท (สูงสุด 100) ความสนิท 20 ปลดล็อกประลอง และ 50 ขึ้นไปจะได้รับการฟื้นชีวิตหลังพบปะ ทุกการกระทำใช้เวลา 1 ปี เซฟรุ่นเดิมจะเพิ่มข้อมูลสำนักและความสัมพันธ์ให้อัตโนมัติ

ทดสอบระบบ: `node --test tests/game.test.cjs`

## กระเป๋าและหมวดการกระทำ

แผงการกระทำแบ่งเป็น วิถีชีวิต / เดินทาง / สำนัก / สัมพันธ์ / กระเป๋าและร้านค้า หมวดสำนักแสดงตำแหน่งปัจจุบัน ผลงานที่ต้องการสำหรับยศถัดไป และโบนัสตามยศ

เริ่มชีวิตใหม่พร้อมยาฟื้นปราณ 2 ชิ้น ซื้อไอเทมด้วยเงินหรือรับไอเทมสุ่มเมื่อผจญภัยสำเร็จ: ยาฟื้นปราณฟื้นชีวิต 30, คัมภีร์ยุทธ์เพิ่มค่าฝึกฝน 25, โอสถเสริมกำลังเพิ่มพลังยุทธ์ 4 ซื้อและใช้ไม่เสียปี ไอเทมใช้แล้วหมดไป เก็บได้ชนิดละ 999 ชิ้น และไม่สามารถใช้ยาขณะชีวิตเต็มหรือทำรายการหลังจบชีวิต เซฟเก่ายังคงความคืบหน้าและเริ่มกระเป๋าว่าง

## ต่อสู้ ความเกรงใจ และอาวุธ

- ทุกการกระทำแสดงข้อความพร้อมอนิเมชัน รองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์
- ทำเนียบสำนักมี 16 ตัวละคร (4 คนต่อสำนัก) แสดงตำแหน่ง พลังรวม อาวุธ ความเกรงใจ และความแค้น เดินทางไปยังสำนักเพื่อท้าประลองหรือโจมตีศิษย์ในพื้นที่
- การต่อสู้คำนวณอัตโนมัติสูงสุด 8 ยก ทั้งสองฝ่ายโจมตีและตอบโต้พร้อมกันในแต่ละยก มีรายงานผลและอนิเมชัน ใช้เวลา 1 ปีต่อการต่อสู้ ศัตรูเริ่มด้วยพลังชีวิต 100 ในการพบกันแต่ละครั้ง
- ประลองหยุดเมื่อชีวิตผู้เล่นเหลือ 1; ชนะได้ค่าฝึกฝน 20 ชื่อเสียง 4 และผลงาน 5 หากอยู่สำนักเดียวกัน การโจมตีจริงอาจเสียชีวิต ลดมิตรภาพ 15 ชื่อเสียง 5 และเพิ่มความแค้น 25 โดยมีคำยืนยันก่อนลงมือ
- ความเกรงใจคิดจากพลังรวม ชื่อเสียง มิตรภาพ และความแค้น ถ้าถึง 70 และความแค้นต่ำกว่า 30 คู่ต่อสู้ยอมหลีกทางในการท้าประลองโดยไม่ต่อสู้หรือให้รางวัล
- อาวุธ 4 แบบ: กระบี่ไม้ (+3), กระบี่เหล็ก (+10), ทวนเงิน (+18), กระบี่หยกเมฆา (+30) ซื้อและสวมใส่จากกระเป๋าได้ครั้งละหนึ่งชิ้น โบนัสมีผลต่อการต่อสู้ ผจญภัย และความเกรงใจ เซฟเก่าได้รับกระบี่ไม้โดยไม่เสียความคืบหน้า

ตรวจไวยากรณ์ทั้งสองไฟล์: `node --check mechanics.js && node --check game.js`

## แผนที่พื้นที่และแผนผังสำนัก

หมวดเดินทางมีแผนที่สี่ทิศและแผนที่พื้นที่ปัจจุบัน หมวดสำนักมีแผนผังภายใน ทั้งสองแสดงตำแหน่งเดียวกันที่บันทึกไว้ในเซฟ:

- ชุมชนหน้าสำนัก: พบเถ้าแก่หวังเพื่อเปิดร้านค้า และป้าหลี่เพื่อรับงาน
- ประตูสำนัก: พบศิษย์ใหม่ ฝากตัวหรือรับภารกิจ
- ลานฝึกยุทธ์: พบศิษย์เอกและฝึกวิชา
- หอคัมภีร์: พบผู้อาวุโสและศึกษาวิชา
- เรือนศิษย์: พบศิษย์ชั้นในและพักฟื้น

เดินภายในพื้นที่ไม่เสียปี ข้ามทิศใช้ 1 ปีและเริ่มที่ชุมชน ต้องอยู่จุดเดียวกับตัวละครจึงพูดคุย ให้ของขวัญ ประลอง หรือโจมตีได้ ทำเนียบและหมวดสัมพันธ์มีปุ่มไปพบ ตัวละครบนแผนที่เพิ่มมิตรภาพร่วมของสำนักนั้น เซฟเก่าเริ่มตำแหน่งที่ชุมชนโดยคงข้อมูลเดิม

ไฟล์ `world.js` ดูแลสถานที่และการพบปะ ตรวจไวยากรณ์ด้วย `node --check world.js`
